# Customer Churn Prediction

This project predicts whether a customer is likely to churn using Machine Learning.

## Technologies Used

- Python
- Streamlit
- Scikit-learn
- Pandas
- Joblib

## Model

- Logistic Regression

## Features

- Customer Age
- Gender
- City
- Total Orders
- Total Spending
- Average Order Value
- Last Order Days
- Customer Tenure
